# web-dev-learning
Web Development Learning

This repository contains the websites and projects I created during my web development internship. It documents my progress as I learned HTML, CSS, Flexbox, CSS Grid, and Web Forms.

I started with basic HTML exercises and gradually moved into building multi-page websites with more structure, layout, and functionality. I have also revisited some earlier projects to fix issues, improve my code, and replace images that I did not have permission to use.

Projects
Movie Mania

Lesson: HTML Review
Skills: HTML

My first website project during the internship. A simple one-page movie-themed website created during our HTML review.

Favourite Musician

Created: July 29, 2026
Lesson: HTML Review
Skills: HTML, Semantic HTML

A one-page website about my favourite musician, Michael Jackson. I later revisited this project to improve the HTML structure, practice semantic HTML, and address image licensing.

Favourite Things

Skills: HTML, CSS

A personal webpage featuring some of my favourite things, including video games and music. This project was created during our CSS review and gave me an opportunity to start applying styling to my HTML.

Lesson: Flexbox
Skills: HTML, CSS, Flexbox

A two-page retro gaming website focused on Nintendo 64 games. The project includes a home page and a reviews page where I share my thoughts and memories about games I played growing up.

Indigenous Artists Showcase

Created: August 12, 2026
Lesson: Flexbox 2
Skills: HTML, CSS, Flexbox, Semantic HTML

A multi-page showcase featuring Indigenous artists and their work. This project gave me more practice with Flexbox, semantic HTML, and organizing information and images using elements such as <article>, <figure>, and <figcaption>.

I later revisited the project and replaced images that I did not have permission to use with placeholders.

Moswa Cookbook

Created: August 17, 2026
Lesson: Introduction to CSS Grid
Skills: HTML, CSS, CSS Grid

A two-page cookbook website featuring recipes with a moose-inspired theme. This project was my introduction to CSS Grid and gave me practice creating layouts with multiple columns and rows.

Volunteer Form

Created: August 27, 2026
Lesson: Introduction to Web Forms
Skills: HTML, CSS, Web Forms

A volunteer registration website created for a community fireside chat focused on MMIWG2S+ awareness, remembrance, and action.

I created this website in one day. I was especially proud of this project because I was able to take what I had learned and build a complete, purposeful website within a single day.
